مسك للحديد والبويات — إدارة أحمد الجمال

تم تحديث النسخة لتشمل:
- واجهة خضراء حديثة وحركات انتقالية وSplash Screen عند التشغيل.
- هوية الفاتورة: مسك للحديد والبويات / إدارة أحمد الجمال / رقم الهاتف الحالي.
- Designed by Mazen Awad يظهر كتوقيع جانبي وفي شاشة البداية والفاتورة.
- المبيعات والبيع السريع والمخزون والعملاء والموردين والمشتريات.
- المرتجع يسجل كحركة مستقلة سالبة في اليومية، يعيد الكمية للمخزن، ويعيد حساب صافي الفاتورة والربح.
- اليومية تجمع الفواتير والبيع السريع والمرتجعات، والأحدث أولًا.
- التقارير تحسب تكلفة البضاعة والربح مع تأثير المرتجعات.
- لوحة المتابعة تعرض المبيعات والمرتجعات والتكلفة وصافي الربح وقيمة المخزون والمديونيات.
- التقارير تحتوي على أسهم مقارنة بالفترة السابقة.
- التاريخ والوقت في الفواتير واليومية.
- BUILD-WINDOWS.bat لإنشاء EXE لويندوز 64-bit (NSIS + Portable).

ملاحظة: ملفات EXE نفسها تحتاج تشغيل BUILD-WINDOWS.bat على Windows لأن الحزمة الحالية لا تحتوي node_modules.
